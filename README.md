# Combinatorial models in positive geometry

This repository accompanies the PhD thesis entitled *Combinatorial models in positive geometry* by Veronica Calvo Cortes. It is organized into one folder per chapter, each containing the relevant code files needed to reproduce the examples.

Some of this code is also available and documented on MathRepo or Zenodo as part of the resources accompanying papers on which the thesis is based. These resources are linked below. This repository also includes new files and code that are not publicly available elsewhere.
