# Combinatorial models in positive geometry
This is a repository accompanying the PhD thesis entitled "Combinatorial models in positive geometry" authored by Veronica Calvo Cortes. The repository is organized as follows: there is one folder per Chapter with all the relevant code files that can be used to reproduce the Examples. 

Some of this code also appears and is documented in MathRepo or Zenodo with websites that accompanied some of the papers that the thesis is based on, we make this explicit below. However, this repository includes also new files and code that is not available publicly in other places.
