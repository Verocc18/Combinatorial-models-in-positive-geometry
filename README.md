# Combinatorial models in positive geometry

This repository accompanies the PhD thesis entitled *Combinatorial models in positive geometry* by Veronica Calvo Cortes. It is organized into one folder per chapter, each containing the relevant code files needed to reproduce the examples.

Some of this code is also available and documented on MathRepo or Zenodo as part of the resources accompanying papers on which the thesis is based. These resources are linked below. This repository also includes new files and code that are not publicly available elsewhere.

## Related documentation


- The code from **Chapter 2: Beyond associahedra and moduli of points** is also available in this [MathRepo website](https://mathrepo.mis.mpg.de/DihedralSignsM0n/index.html).

- Part of the code from **Chapter 3: Toric varieties, embedded polytopes and u-relations** is available in the documentation for the Julia package `PositiveChartsToricVarieties`, see [Zenodo website](https://zenodo.org/records/20757633).

- The code from **Chapter 4: Positivity in the Orthogonal Grassmannian** is also available in this [MathRepo website](https://mathrepo.mis.mpg.de/PositiveSkewMatrices/index.html). 



>[!NOTE]
> Code relevant to Section 4.2.3 of this thesis also appeared in the PhD thesis of Joris Koefler and is available in this [Zenodo website](https://zenodo.org/records/20735222). We do not include this code in this repository.
